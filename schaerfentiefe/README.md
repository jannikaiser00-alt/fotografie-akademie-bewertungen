# Schärfentiefe-Rechner der Fotografie Akademie

Eigenständige, deutschsprachige Web-App zur Visualisierung und Berechnung der Schärfentiefe. Sie ist ohne Build-Schritt nutzbar und für GitHub Pages geeignet: Dateien in ein Repository legen und Pages auf den Hauptordner einstellen.

Die Markenfarben sind aus dem bereitgestellten Logo abgeleitet. Das Logo liegt als `fa-logo.png` im Projekt.
